# NeetCode-150

编程面试刷题资料，整理日期：2026-11-06。

## 题单

- [Grind 75：75 道题](grind-75.md)：按官方数据推荐顺序整理，含难度、主题和预计用时。
- [NeetCode 150：150 道题](neetcode-150.md)：按算法主题分类，含难度、LeetCode 题目链接和视频讲解链接。

题单保存的是题目索引，不包含题目全文、视频文件或答案代码。两套题单存在重叠，不等于 225 道不同题目。NeetCode 分类采用官方开源数据中的分类，可能与网站当前导航有所不同；难度也可能随平台更新。

## 使用方法

1. 基础语法学完后开始练题，遇到不懂的概念再补齐。
2. 做题时按「理解题意 → 选择算法 → 规划步骤 → 编写代码 → 测试 → 分析复杂度」练习讲解。
3. 能独立完成后，将题目前的 `- [ ]` 改为 `- [x]` 并提交保存。
4. 间隔复习，对卡住的题目记录原因，优先重做。
